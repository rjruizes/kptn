{# A run's header, as a replaceable fragment. Rendered in two places: on the run page, and as the ``run_header`` SSE frame that closes a stream. It therefore takes only the run and the three flags below -- never the request -- so it can be rendered straight from Python. Everything here comes from the run *row*, which is why it has to be replaceable at all. A run that goes terminal under an open stream leaves the page showing "still running" and offering Stop for a process that is gone; the closing frame swaps this whole section for the one the server would render now. Three controls, and the difference between them is the point: ``Stop`` asks the worker to wind down. It records intent and signals; it never writes an outcome, because only the worker knows whether cleanup finished. ``Run again`` the obvious next action from a finished run. It owns a ``run-form`` so the base page's profile selector (which carries ``form="run-form"``) keeps working here. ``Force-finish`` the escape hatch for a worker whose liveness can never be determined, and which reconciliation therefore cannot settle. It abandons a possibly-live process, so it is behind a disclosure *and* a typed confirmation -- never one click away from Stop. #}
