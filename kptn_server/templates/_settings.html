{# The settings button and the modal it opens: the reader's own preferences, and which kptn is serving the page. Included at the right end of the app bar on every page, so a preference is reachable from wherever the reader is -- Sound in particular is set before a run is started, not on the run page after it has begun. Sound is on by default and remembered in the browser. app.js plays a tone when a watched run's final status frame arrives -- rising for a run that succeeded, falling for any other ending -- and reads this checkbox by its id at that moment, so it sounds only for a run that ends while its page is open. The version answers "is this the version I just installed?" from the page itself, since an install that silently kept the old code looks the same otherwise. Nobody needs it until they are asking that, so it lives here rather than on the page. A native ````: the browser supplies the focus trap, Escape, and the backdrop. app.js opens it with ``showModal()`` and closes it on a backdrop click; the Close button needs no script at all (``method="dialog"``). #}
