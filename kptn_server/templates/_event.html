{# The run log's rows and sections. Macros only, so this template can be rendered from Python for a single SSE frame (via ``get_template(...).module.event_row``) as well as included in a loop by the console. Both paths therefore produce byte-identical markup: what the stream appends is exactly what a page reload would have rendered. The sections -- one per task, table or item -- are here for the same reason. The stream sends a section as ``section_shell``, open and empty, and appends rows into it; the page renders the same markup around the rows it already holds. Where every row goes is decided in ``kptn_server.console_layout``, never here and never in app.js. Every value here goes through Jinja's autoescaping. ``event.text`` is pipeline output -- untrusted bytes read out of the run's log file -- and this is the only place it is turned into markup. Do not add ``| safe`` to it. #} {% from "_status.html" import status_icon %} {# One event: an element per event, holding a line per line it shows. Every event has one, hidden or not -- the run's counters and the stream's resume cursor count them -- and its ``id`` is what the history page's warning links point at. A line's number is empty when the stream sends it; app.js numbers it after the last line on the page. #} {% macro event_row(event) -%}
{%- for line in event.shown %}
{{ event.first_line + loop.index0 if event.first_line else "" }}{{ event.clock }}{{ line }}
{% endfor -%}
{%- endmacro %} {% macro lines_text(count) -%} {{ "no output" if not count else ("1 line" if count == 1 else "{:,} lines".format(count)) }} {%- endmacro %} {# The right-hand end of a section's heading: how it ran, how long, how much it printed, and how it ended. Its own element, with an id, because the task finishes after its section was sent: the ``task_finished`` frame replaces just this. app.js keeps the line count current as rows stream in. #} {% macro section_outcome(section, finished) -%} {%- set state = finished.status if finished and finished.status else section.state -%} {%- if section.runner %}{{ section.runner }} · {% endif -%} {%- if finished and finished.duration %}{{ finished.duration }} · {% endif -%} {{ lines_text(section.lines) }} {{ status_icon(state, count=section.warnings) }} {%- endmacro %} {# One section: a heading that folds it, then its lines. {{ body }}
{%- endmacro %} {# A section as the stream first sends it: open, with nothing in it yet. #} {% macro section_shell(section) -%} {{ section_markup(section, true, "") }} {%- endmacro %} {# The log, as ``build_console`` lays it out: sections and the run's rows. #} {% macro console_items(items) -%} {% for item in items %}{% if item.body_id is defined %}{{ section_markup(item, item.open, console_items(item.children)) }}{% else %}{{ event_row(item) }}{% endif %}{% endfor %} {%- endmacro %}
