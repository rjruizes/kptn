{# One console event, as one list item. Macros only, so this template can be rendered from Python for a single SSE frame (via ``get_template(...).module.event_row``) as well as included in a loop by the console. Both paths therefore produce byte-identical markup: what the stream appends is exactly what a page reload would have rendered. The folds -- one per pipeline or stage, one per task -- are here for the same reason. The stream sends a fold as ``fold_shell``, open and empty, and appends rows into its body; the page renders the same markup around the rows it already holds. Where every row goes is decided in ``kptn_server.console_layout``, never here and never in app.js. Every value here goes through Jinja's autoescaping. ``event.text`` is pipeline output -- untrusted bytes read out of the run's log file -- and this is the only place it is turned into markup. Do not add ``| safe`` to it. #} {% macro event_row(event) -%}

    {{ event.text }}
