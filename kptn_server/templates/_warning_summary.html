{# A run's warnings, grouped. Macros only, so the same rendering serves the run page's completion summary and the history list's per-run badge -- one place decides how a warning is worded, and neither surface can drift from the other. ``summary`` is the dict built by ``runs.warning_summary()``. It is already shaped for display (headline, per-group occurrence label, anchors), because a template is the wrong place to pluralize or to build a fragment href. Grouping is *presentation*. The store keeps every warning occurrence, and every one of them is linked here: ``occurrences`` is the group's stored sequence list, and each anchor points at the console row that event rendered. Nothing is collapsed away, so a repeat is always reachable. Every value below is pipeline-authored text -- a warning message, a task name, a warning category -- and reaches the page through Jinja's autoescaping. Do not add ``| safe`` to any of it. #} {% macro warning_summary(summary) -%} {% if summary.total %}

{{ summary.headline }}

    {% for group in summary.groups %}
  • {% if group.task %}{{ group.task }} {% else %}outside any task{% endif %} {{ group.category }} {{ group.occurrence_label }}

    {{ group.sample_message }}

    {%- for occurrence in group.occurrences %} #{{ occurrence.sequence }} {%- endfor %}
    • {% endfor %}
{% else %}

No warnings.

{% endif %} {%- endmacro %} {% macro warning_badge(summary) -%} {# The compact form for a history row: the same headline, plus one sample so the reader can tell whether it is worth opening the run. The full group list, with its per-occurrence anchors, lives on the run page -- the anchors only mean anything next to the console they point into. #} {% if summary.total %} {{ summary.headline }} {% if summary.groups %}{{ summary.groups[0].sample_message }}{% endif %} {% else %} no warnings {% endif %} {%- endmacro %}
