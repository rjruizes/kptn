{# How a task went, as one small icon -- shared by the rail and the log's section headings so the two always agree. Colour and shape both carry the state (a check, a triangle, a cross...), and the label says it in words for assistive technology and on hover. ``count`` turns a warned success into the heading's pill: the triangle and how many warnings. ``warned`` alone marks it in the rail, where there is no room for a count. #} {% macro status_icon(state, warned=false, count=0) -%} {%- set warns = warned or count > 0 -%} {%- set words = { "succeeded": "Succeeded", "failed": "Failed", "cached": "Cached", "running": "Running", "waiting": "Waiting", "not_run": "Not run", "interrupted": "Interrupted", "bypassed": "Bypassed", "stopped": "Stopped", } -%} {%- set word = words.get(state, state | capitalize) -%} {%- if state == "succeeded" and warns -%} {%- set label = word ~ " with " ~ count ~ (" warning" if count == 1 else " warnings") if count else "Has warnings" -%} {%- if count %}{{ count }}{% endif -%} {%- else -%} {%- if state in ("succeeded", "cached") -%} {%- elif state == "failed" -%} {%- elif state == "running" -%} {%- elif state == "interrupted" or state == "stopped" -%} {%- elif state == "bypassed" -%} {%- else -%} {%- endif -%} {%- endif -%} {%- endmacro %}
